## 🧮 INTELLIGENCE CALCULATIONS

### 1. IPC Running Bill Formula

```
Gross Certified (This IPC)
  − Previous Cumulative IPCs
  = Net Work This Period

  + Price Escalation (PEC Clause 70)
  − Retention Money (typically 5-10%)
  − Mobilization Advance Recovery
  − Secured Advance (site materials)
  = Net Before Tax

  − WHT (7.5% or 15%)
  − Provincial Tax (13-16%)
  = NET PAYABLE
```

**Retention Release:** At completion + DLP expiry  
**Mobilization Recovery:** Pro-rata up to 80% completion

### 2. PEC Clause 70 — Price Escalation

```
Adjustable Base = Billed Amount × (1 - Fixed Component)
Fixed Component = 15% (non-adjustable)

For each material (Steel, Cement, Bitumen, Fuel, Labor):
  Adjustment = Base × Component% × [(Current WPI - Base WPI) / Base WPI]

Total Escalation = Sum of all component adjustments
```

**WPI = Wholesale Price Index** (Pakistan Bureau of Statistics)  
**Update Frequency:** Quarterly

### 3. BOQ Variance Analysis

```
Estimated Cost = Estimated Qty × Estimated Rate
Actual Cost    = Actual Qty × Actual Rate
Variance       = Actual Cost - Estimated Cost
Variance %     = (Variance / Estimated Cost) × 100

Alert Levels:
  > +20%  → CRITICAL (raise PEC escalation claim)
  > +10%  → WARNING (monitor closely)
  < -10%  → FAVOURABLE (verify quality, lock purchase)
  Others  → OK (within acceptable range)
```

### 4. Equipment Productivity

```
Fuel Per Hour   = Total Fuel Litres / Hours Logged
Output Per Hour = Total Output Qty / Hours Logged
Fuel Per Output = Total Fuel Litres / Output Qty

Fuel Cost = Fuel Litres × PKR 390.62 (diesel rate)
Cost Per Output Unit = Fuel Cost / Output Qty
```

### 5. Subcontractor Retainage

```
Work Order Value:         PKR X
Retainage %:              10% (typical)
Amount Certified To Date: PKR Y

Total Retainage Deducted = Y × 10%
Amount Released (DLP):    PKR Z
Retainage Balance:        (Y × 10%) - Z
Net Paid To Date:         Y - (Y × 10%) + Z
```

**Release Trigger:** DLP completion + final inspection sign-off

### 6. Cash Flow S-Curve Projection

```
Monthly Billing = (Monthly Weight / Total Weight) × Contract Value

Weight Distribution:
  Front 20%: Heavy mobilization phase
  Mid 50%:   Peak construction phase (bell curve)
  Last 30%:  Tapering finishing phase

Retention deducted each month: Typically 5%
```

## 🚨 VARIANCE ALERTS

### Material Rate Comparison
```
BOQ Rate vs Market Rate Variance:

> +20%  → 🔴 CRITICAL
  Action: Raise PEC Clause 70 escalation claim immediately

> +10%  → 🟡 WARNING
  Action: Monitor closely, consider forward purchase or escalation notice

< -10%  → 🟢 FAVOURABLE
  Action: Market rate lower than BOQ. Verify quality and lock in purchase.

Others  → ⚪ OK
  Action: Rate within acceptable range
```

### Safety Incident Severity
```
CRITICAL → Fatality, major injury, site shutdown
HIGH     → Lost-time injury, equipment damage >PKR 1M
MEDIUM   → First aid case, near-miss
LOW      → Safety observation, minor violation
```

### Quality Test Status
```
PASSED  → Within specification limits
FAILED  → Retesting required, possible rejection
PENDING → Awaiting lab results (3-7 days for concrete)
```

## 💡 USAGE TIPS

### Best Practices
1. **Update Material Rates Quarterly** — Align with PEC Clause 70 WPI indices
2. **Log Equipment Daily** — Fuel consumption tracking for cost control
3. **Submit IPCs Promptly** — Within 7 days of work completion (cash flow)
4. **Monitor BOQ Variance** — Weekly review to catch overruns early
5. **Retain Documentation** — All WHT/provincial tax certificates for annual reconciliation
6. **PEC License Renewal** — Start process 60 days before expiry

### Common Pitfalls to Avoid
- ❌ Missing WHT filing deadline (7th) → PKR 10K penalty + 1.25%/month interest
- ❌ Not claiming PEC escalation → Lost profit on material price increases
- ❌ Over-recovery of mobilization → Cash flow crunch in final 20%
- ❌ Ignoring retention tracking → Surprise loss at DLP release
- ❌ Using outdated material rates in BOQ → Tender loss or profit erosion
