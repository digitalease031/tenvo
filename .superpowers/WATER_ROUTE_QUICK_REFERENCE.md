## How to Use (Mobile)

### Bills Tab
1. Tap **[🖨️ Print ▼]** → Choose format (Print/PDF/A4)
2. Tap **[📄 Generate]** → Create new bills
3. Tap **[🔔 Remind]** → Send reminders to unpaid customers

### Daily Sheet Tab
1. Tap **[🖨️ Checklist ▼]** → All print options in one menu:
   - Checklist (58mm/80mm/PDF)
   - Area List (A4/A5)
   - Daily Bills (Print/PDF)
2. Tap **[💾 Save]** → Save the day sheet

## How to Use (Desktop)

### Bills Tab
**Print Options Group:**
- Click **[Print all weekly ▼]** main button to print
- Click **[▼]** dropdown for alternatives (PDF, A4 Summary)

**Bill Management Group:**
- Click **[Generate bills]** to create invoices
- Click **[Remind unpaid]** to send notifications

**Navigation:**
- Click **[Open invoices]** to see invoice list

### Daily Sheet Tab
**Print Group:**
- **Checklist:** 58mm thermal (default), 80mm, or PDF
- **Area List:** A4 full page (default) or A5 compact
- **Daily Bills:** Print all or Download PDF

**Save:**
- Click **[Save day]** to save changes

## Common Workflows

### Daily Delivery Route
1. Open **Daily Sheet** tab
2. Select today's date
3. Fill delivery data (Del/Rec columns)
4. **[Save day]**
5. **[Checklist ▼]** → Print 58mm for riders
6. **[Area List ▼]** → Print A4 for register

### Weekly Billing
1. Open **Bills** tab
2. Select **Weekly** period
3. Choose current week
4. **[Generate bills]** → Create invoices
5. **[Print all ▼]** → Print thermal bills
6. **[Remind unpaid]** → Send reminders

### End of Month
1. Open **Bills** tab
2. Select **Monthly** period
3. Choose current month
4. **[Generate bills]** → Create invoices
5. **[Print all ▼]** → A4 Summary Report
6. **[Open invoices]** → Review in hub
