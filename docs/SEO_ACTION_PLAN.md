## Content Creation Checklist

Use this for every piece of content:

### Before Writing
- [ ] Keyword research done
- [ ] Competitor analysis complete
- [ ] Outline created
- [ ] Target word count: 1,500+

### While Writing
- [ ] Include primary keyword in title
- [ ] Include keyword in first paragraph
- [ ] Use keyword naturally throughout
- [ ] Add 3-5 internal links
- [ ] Add 2-3 external links
- [ ] Include images with alt text
- [ ] Add FAQ section
- [ ] Include clear CTA

### Before Publishing
- [ ] Title is 50-60 characters
- [ ] Meta description is 150-160 characters
- [ ] Keywords in title and description
- [ ] All images optimized (< 100KB each)
- [ ] All links work
- [ ] Mobile preview looks good
- [ ] Desktop preview looks good
- [ ] Proofread for errors
- [ ] Team review complete

### After Publishing
- [ ] Submit URL to Search Console
- [ ] Share on LinkedIn
- [ ] Share on Twitter/X
- [ ] Share on Facebook
- [ ] Email to list (if applicable)
- [ ] Monitor engagement first 24 hours
- [ ] Add to content calendar
