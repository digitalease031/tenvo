## 📊 Analytics & Tracking

### Google Analytics
- Property ID: Set via `NEXT_PUBLIC_GA_MEASUREMENT_ID`
- Key Events: Trial signups, demo store visits, pricing views

### Search Console Metrics
- **Good:** Impressions growing, CTR > 3%, average position improving
- **Concerning:** CTR < 1%, position dropping, crawl errors

### Core Web Vitals Targets
- **LCP** (Largest Contentful Paint): < 2.5s
- **FID** (First Input Delay): < 100ms
- **CLS** (Cumulative Layout Shift): < 0.1

## 🏆 SEO Best Practices

### Do's ✅
- Write for humans first, search engines second
- Use keywords naturally in content
- Create unique, valuable content
- Optimize page load speed
- Make site mobile-friendly
- Build quality backlinks
- Update content regularly
- Monitor analytics weekly
- Fix crawl errors promptly
- Submit new content to search engines

### Don'ts ❌
- Don't keyword stuff
- Don't buy backlinks
- Don't duplicate content
- Don't hide text or links
- Don't ignore mobile users
- Don't forget alt text on images
- Don't use generic meta descriptions
- Don't neglect internal linking
- Don't forget schema markup
- Don't ignore search console warnings

## 🎨 Image Requirements

### File Formats
- **Primary:** WebP (already configured)
- **Fallback:** JPEG for photos, PNG for graphics
- **Vector:** SVG for logos and icons

### Sizes
- **Hero Images:** 1920x1080px (16:9)
- **Blog Featured:** 1200x630px (1.91:1 - OG standard)
- **Product Images:** 800x800px (1:1)
- **Thumbnails:** 400x300px (4:3)

### Optimization
- Compress images (aim for < 100KB per image)
- Use `next/image` component (automatic optimization)
- Always add descriptive alt text
- Include keywords in filename when relevant

## 🆘 Quick Troubleshooting

### Traffic Drop
1. Check Search Console for manual actions
2. Look for technical errors (crawl, index)
3. Review recent content changes
4. Check for algorithm updates
5. Monitor competitors

### Ranking Drop
1. Check page still indexed (`site:url` in Google)
2. Review on-page SEO (title, description, content)
3. Check for broken links
4. Review backlink profile
5. Compare to competitor pages

### Not Ranking
1. Verify page is indexed
2. Check for no-index tag
3. Review keyword difficulty
4. Assess content quality
5. Build more backlinks
